# Data Professional Survey Dashboard

## Overview
This Power BI dashboard provides insights into the survey responses of data professionals across different job roles, programming languages, salaries, and job satisfaction levels. It helps analyze trends related to job roles, salary distribution, and demographic details.

## Features
- **Country Distribution**: A visual representation of where survey respondents live.
- **Programming Language Popularity**: A bar chart showcasing the most preferred programming languages among data professionals.
- **Average Salary by Job Title**: A comparative analysis of salaries across different job roles such as Data Scientist, Data Engineer, Data Analyst, etc.
- **Demographics**:
  - **Average Age of Survey Respondents**
  - **Total Count of Survey Takers**
- **Job Satisfaction**:
  - "How happy are you considering your current job?"
  - "How happy are you with your salary?"
- **Gender-Based Salary Analysis**: A donut chart showing the salary distribution between male and female respondents.

## Data Processing
- **Data Transformation**: Performed using Power Query Editor in Power BI to clean, structure, and enhance the dataset.
- **DAX Queries**: Implemented various DAX (Data Analysis Expressions) queries for calculations and measures such as:
  - Average salary calculations
  - Aggregations for job satisfaction scores
  - Conditional formatting for visual enhancements

## Tools Used
- **Power BI**: For data visualization and reporting.
- **Power Query Editor**: For data transformation and preparation.
- **DAX (Data Analysis Expressions)**: For advanced data calculations and measures.

## How to Use
1. Open the Power BI file containing this dashboard.
2. Interact with the visualizations using filters and slicers to gain insights.
3. Hover over charts and graphs for additional tooltips and details.
